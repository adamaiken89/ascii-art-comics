## Style comparison

| | A. Kaomoji | B. Manga | C. Noir |
|---|---|---|---|
| Border weight | heavy | light | none |
| Face type | kaomoji | chibi box | minimal ASCII |
| Best for | punchy gags, memes | narratives, timing | dialogue, prose |
| CJK risk | high (kaomoji fullwidth) | low (designed for it) | none |
| Panels per comic | 2-4 | 3-6 | 1-6 |
| Density | high | medium | low |

---

## When to pick which

- **A** if user wants expressive, meme-coded, English-first with CJK kaomoji
- **B** if user wants CJK-native storytelling with 4-koma timing
- **C** if user wants minimal, terminal-log, dialogue-only
