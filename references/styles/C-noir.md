# Style C — Stick-Noir

No frames, deadpan faces, dialogue carries the story.

## Look

- Border: None (panels separated by blank lines or `---`)
- Faces: Minimal ASCII (`o_o`, `>_<`, `-_-`)
- Layout: Free-form vertical sequence
- Dialogue: bare, in quotes

## When to use

- Dialogue-heavy scenes
- Prose-poem / vignette feel
- When CJK safety matters most (no alignment to break)
- Terminal-log aesthetic

## Layout

```
           o_o

    "the meeting starts in 5"

                       >_<

        "i haven't read the doc"

                                  -_-

             "no one has"
```

## Rules

- No panel borders
- Faces inline with text or on own line
- Quotes around dialogue
- Blank lines as pacing
- Faces minimal — no kaomoji, no chibi

## Anti-patterns

- Adding panel borders (ruins the form)
- Using kaomoji (over-registers)
- Multi-character scenes (hard to track without borders)
- Action sequences (needs visual structure noir lacks)
