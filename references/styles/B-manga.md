# Style B — Panel-Manga

Thin frames, chibi faces, CJK-native, 4-koma flow.

## Look

- Border: Light (`┌ ─ ┐ │ └ ┘`)
- Faces: Chibi box (`╭──╮ │◕_◕│ ╰──╯`)
- Layout: 4-koma (2x2 or 1x4 grid) typical
- Dialogue: CJK inside panel, no bubble border

## When to use

- CJK-first content
- Multi-panel narrative
- Storytelling / sequential scenes
- Tonal work (slice of life, comedy timing)

## Layout

```
┌────────┬────────┬────────┬────────┐
│  ╭──╮  │  ╭──╮  │  ╭──╮  │  ╭──╮  │
│  │◕‿◕│  │  │◑_◑│  │  │╥_╥│  │  │>_<│  │
│  ╰──╯  │  ╰──╯  │  ╰──╯  │  ╰──╯  │
│        │        │        │        │
│ 「今天  │ 「吃啥?」│ 「隨便」│ 「吃飯」│
│  週一」 │        │        │        │
└────────┴────────┴────────┴────────┘
```

## Rules

- 4-koma grid is the canonical layout
- Dialogue in 「」 brackets (fullwidth CJK quote)
- Faces centered top of panel
- Body optional, often implied
- Panel gutters: 1 cell (`│` between vertical panels)

## Anti-patterns

- Heavy borders (style A territory)
- Kaomoji faces (wrong register)
- Single panel (no 4-koma timing)
- More than 6 panels
