# Style A — Kaomoji-Cinematic

Default. Heavy boxes, big faces, kaomoji emotes, English or CJK dialogue.

## Look

- Border: Heavy (`╔ ═ ╗ ║ ╚ ╝`)
- Faces: Kaomoji fullwidth
- Layout: 2-4 panels per comic
- Dialogue: in bubbles with kaomoji-tail OR plain text below face

## When to use

- Punchy gags
- Meme-coded expressions
- Short narratives
- English-first dialogue with CJK kaomoji

## Layout

```
╔══════════════════════════════╗
║                              ║
║      (◕‿◕)                   ║
║       │                      ║
║      ╱ ╲                     ║
║                              ║
║  ╭──────────────────────╮    ║
║  │  hello there!        │    ║
║  ╰──────────────────────╯    ║
║                              ║
╚══════════════════════════════╝
```

## Rules

- Bubble inside panel OR panel itself is the bubble
- Tail from bubble to face (or skip tail if face is inside bubble)
- Kaomoji always 1-3 lines tall
- Body optional (stick figure OK, full body for action)
- No greyscale — use density ramp ` .:-=+*#%@` if shading needed

## Anti-patterns

- Mixing kaomoji with chibi-box face in same comic
- Heavy borders with light borders in same comic
- More than 4 panels (manga territory)
